Clara

An AI finance app that turns messy Argentine bank statements into clean personal finances.

Solo project · Flask, Claude API

The problem

Argentine bank and card statements arrive as inconsistent PDFs, and local reality — the MEP dollar, the same recurring merchants — breaks every off-the-shelf budgeting app.

What I built

A Flask web app, built solo and from scratch across several sessions. It parses statement PDFs, categorizes each transaction with the Claude API, applies MEP exchange rates, and remembers how every merchant was categorized so it gets more accurate the more it's used. The interface is warm and deliberately minimal.

Key decisions

  • Merchant memory instead of re-classifying every run — faster, and more accurate over time.
  • MEP exchange rates baked in, because ARS/USD is the unit people here actually budget in.
  • PDF-first ingestion, because that's how Argentine banks actually hand over data.

Outcome

A working product I run on my own finances — scoped, built, and shipped end to end as a non-engineer.
