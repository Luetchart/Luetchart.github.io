Audience Builder

Self-serve CRM segmentation for marketers — and the agentic-analytics architecture behind it.

Google Apps Script · BigQuery, Gemini CLI (MCP), Vertex AI

The problem

Building CRM audiences meant waiting on data or engineering, or writing SQL yourself — a bottleneck for a team moving fast across 14 markets.

What I built

Audience Builder Pro, a Google Apps Script tool in our brand identity that lets marketers assemble segments themselves. It sits inside a broader agentic-analytics architecture I designed: a structured data dictionary feeding Gemini CLI to query BigQuery through MCP, evolving from an Apps Script v1 toward a Vertex AI engine.

Key decisions

  • A structured data dictionary first — agentic querying is only as good as the schema it can understand.
  • Ship a simple Apps Script v1 to win adoption, then upgrade the engine underneath without changing the marketer's experience.

Outcome

Turned a technical, engineering-dependent task into something non-technical marketers do for themselves.
